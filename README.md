# ⚽ AI Football Assistant — Homework 1

Простой AI-ассистент, который принимает вопрос про футбол, получает **реальные данные из интернета** и возвращает понятный ответ. Всё в одном файле `index.html` — интерфейс и логика на чистом JavaScript, **без бэкенда**.

---

## 🚀 Запуск

1. Открой `index.html` в браузере (двойной клик по файлу).
2. Задай вопрос или нажми готовый пример.

Ключи уже вставлены в файл. Если Gemini перестанет отвечать (ключ временный) —
создай новый на https://aistudio.google.com/app/apikey (начинается с `AIza`)
и замени `GEMINI_API_KEY` в начале `<script>` в `index.html`.

Примеры вопросов:
- «Покажи таблицу АПЛ»
- «Ближайшие матчи Барселоны»
- «Последние результаты Реал Мадрид»
- «Расскажи о клубе Ливерпуль»

## 📄 Краткое описание (для сдачи)

**Какой инструмент я использовал?**
Ассистент написан как одна веб-страница `index.html` на чистом **JavaScript** —
и интерфейс, и вся логика работают прямо в браузере, отдельный сервер не нужен.
В качестве AI-слоя используется **Google AI Studio (Gemini API)**, модель
`gemini-flash-latest` — бесплатно и без привязки карты.

**Какой API / источник данных?**
Реальные футбольные данные берутся из **TheSportsDB** — бесплатного публичного API,
который работает прямо из браузера (CORS разрешён, регистрация не нужна,
используется общий тестовый ключ `3`). Данные: турнирные таблицы лиг, ближайшие и
прошедшие матчи команд, информация о клубах.

**Как работает ассистент?**
Ассистент работает в три шага (все шаги видны в блоке «Как ассистент получил ответ»):

1. **Понимание вопроса (AI).** Пользователь пишет вопрос на естественном языке.
   Gemini выступает «маршрутизатором»: возвращает строгий JSON — какой тип данных
   нужен (`table` / `next` / `last` / `team_info`), какую лигу выбрать и как называется
   команда по-английски (например «Барселоны» → `Barcelona`).

2. **Получение реальных данных.** По этому плану JS делает `fetch`-запрос к нужному
   endpoint TheSportsDB и получает свежий JSON с реальными результатами.

3. **Суммаризация (AI).** Gemini получает этот JSON и превращает его в короткий,
   понятный ответ на русском с конкретными цифрами и названиями — ничего не выдумывая.

```
Вопрос → [Gemini выбирает запрос] → [TheSportsDB отдаёт данные] → [Gemini суммирует] → Ответ
```

Прямо на странице есть блок **«🧾 API-запросы (сырой JSON)»**: по каждому вызову видно
endpoint, тело запроса и ответ в формате JSON — и к Gemini, и к футбольному API.
Это наглядно показывает, как ассистент получает данные и как AI их обрабатывает
(удобно для скриншотов задания).

## ⚠️ Заметки
- Ключ Gemini виден в исходном коде страницы — для домашки это нормально,
  но в реальном проекте ключ нельзя хранить в клиентском коде.
- Бесплатный ключ TheSportsDB отдаёт таблицу в урезанном виде (топ-5 команд).
- У бесплатного Gemini есть лимит запросов в минуту; при ошибке `429` подожди ~30 секунд.
